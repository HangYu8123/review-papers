Then open waiting_for_review/<name>/review.html. The format is described in _template/README.md.

Nothing waits for a button. Every decision, note and edit is kept the moment you make it: in this browser, and in an autosave file in this page’s folder once the folder is connected. Close the page whenever you like.

Save batch writes what you decided since the last batch to its own file, named with the date and time. Batches are what gets applied.

· How to apply later ↓

Connect this page’s folder and every decision, note and edit is also written to a file there the moment you make it, so nothing depends on the browser. Until then your work is kept in this browser only.
The dissertation files are unchanged. This page records decisions; they are applied later from the batches you save.
Apply the saved batches later

Each batch is a file next to this page: . Ask Claude to apply them, or run this from the dissertation folder. The first line only lists what would change; the second edits the .tex files after saving backups.


          
Accepted text is written between \hang{<type> start} and \hang{<type> end}, where the type is the label on each card, so it shows as green tags in the PDF. Rejected and undecided items are left as they are. It can be run after every batch: what is already in place is recognised.

        

        

          What is kept if the page is closed
          
    
            
  • In this browser, at once. Every decision, note and edited wording is stored as you make it, and so is the text of an editor you have not saved yet. Reopen the page in the same browser and it is all there, including the list of what is not in a batch yet.
    • 
            
  • In this page’s folder, a moment later. Once the folder is connected, the same working state is written to  after every change. If the browser ever loses its copy (cleared site data, a private window, another browser), connecting the folder reads it back.
    • 
            
  • In batches, when you click Save batch. A batch is the record that gets applied to the dissertation. Decisions that are not in a batch yet are kept by the two layers above, but they are not applied until you save them in one.
    • 
            
  • The line under the Save button says which of these is active. The page asks before closing only if work would be left in the browser alone, or nowhere.
    • 
          

        

        

          Editing, notes, views and keyboard
          
    
            
  • Accept the rest / Reject the rest decides every undecided item in the review, including items hidden by filters. Earlier accept and reject decisions, notes and saved wording are kept. Accept all shown / Reject all shown / Reset all shown changes only the items in the current list.
    • 
            
  • Edit the wording opens the suggested LaTeX for you to change. Your wording is what gets applied if the item is accepted. You can edit before or after deciding, and go back to the suggestion at any time. On a deletion, editing lets you keep a shorter version instead.
    • 
            
  • Two options. Where a second agent disagreed, the card shows the original above both options, each with its reason. Accept A or Accept B chooses one; rejecting leaves the original. Each option can be edited. Accept the rest and Accept all shown leave these cards alone, because accepting needs a choice; Reject the rest and Reject all shown do reject them, since neither option is then written.
    • 
            
  • Add a note attaches a comment to an item, with or without a decision. Notes are saved in the batch and shown when the batch is applied.
    • 
            
  • Readable simplifies the LaTeX, Changes marks removed and added words on the LaTeX source, LaTeX shows the exact source that will be written.
    • 
            
  • Highlight differences works in the Readable view. Where an item rewords existing text, the words that were removed are tinted in the original and the words that were added are tinted in the proposed text. A citation that changed shows its keys. A deletion or an insertion has no second wording to compare, so nothing is tinted there. Untick it to read both versions plain.
    • 
            
  • J / K next and previous item, A accept (option A), B accept option B, R reject, U reset, E edit, M note, N next undecided, 1 2 3 views, H highlight differences, Ctrl+S save batch.
