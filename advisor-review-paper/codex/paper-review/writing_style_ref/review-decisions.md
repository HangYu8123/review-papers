# Review decisions behind Hang's writing style reference

This file indexes the reviews whose decisions the [main reference](hangs-writing-style-reference.md) draws on. Each suggestion was written by an assistant. Hang accepted it, accepted it with an edit, or declined it, and sometimes left a note. In two reviews Hang delegated the remaining decisions, and those decisions are kept with weight 0. The record of each review is in its own file under `reviews/`.

The review folders are removed when a review is finished, so the wording is kept here. Line numbers are those of the file at the time of the review. Dissertation text is LaTeX, as it was on the review page, and slide text is as it was in the deck. Most decisions record no reason, so each "Used in" link leads to a reading of the decision, not to a statement by Hang.
